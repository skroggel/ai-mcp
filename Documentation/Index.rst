============
AI MCP Client
============

:Package name:
    madj2k/ai-mcp

:Namespace:
    Madj2k\AiMcp

:License:
    GPL-2.0-or-later

``madj2k/ai-mcp`` provides a framework-independent MCP client for Madj2k AI integrations. It
implements the MCP protocol boundary and maps MCP capabilities to provider-neutral AI Core tool
contracts.
